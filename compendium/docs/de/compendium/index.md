Compendium ist eine eigenständige Frappe-App, die App-interne Dokumentation aus Markdown-Dateien ausliefert, die beliebige installierte Apps mitbringen.

Die gesammelte Dokumentation finden Sie im Desk unter `/app/docs`. Jede App kann Seiten aus ihrem eigenen `docs/{language}/`-Baum beisteuern.
